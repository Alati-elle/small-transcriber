# Tests

Реальные записи встреч и производные артефакты сюда не копируются.

Будущие regression fixtures должны быть синтетическими или предварительно обезличенными. До подготовки такого fixture допустима только проверка на копии данных вне проекта и без вызова Gemini, если существующего cache достаточно.
